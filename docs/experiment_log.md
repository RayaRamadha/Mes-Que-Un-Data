# Experiment log

One row per experiment, newest at the bottom. The validation protocol is described in
[technical_report.md §7.1](technical_report.md#71-validation-protocol). Notebooks `01`–`07` and the `scratch`
experiments belong to earlier stages of the project; the submitted pipeline is `notebooks/pipeline`.

- **public spellF1 / macroF1** = score against the public 5-minute GT (17 possessions). Used as a correctness check
  only, never to choose a version; one possession ≈ ±6 spellF1 points. Bootstrap intervals are given where available.
- **proxy** = whole-match metric without GT (agreement with Smart Tagging, restarts, held-out pseudo-labels).
- **#poss / duration** = number of possessions and mean duration reported by the file (whole match).
- **decision** = adopted / dropped / to be investigated, with the reason.

Development stages are named by what they added, not by a number:

| Stage | Content |
|---|---|
| heuristic pipeline, `06` rev. 0–4 | team-shape model + nearest team, with the dead-ball detector `03` rev. 3–6 |
| sequence-model stage (`05b` + `06` rev. 5) | first sequence models trained on the 23 external matches |
| set-encoder stage (rev. 6) | 6-model ensemble with the player-set encoder |
| ball-motion stage | + ball-motion and arrival-time features |
| tracking-ball pipeline | + bridged broadcast fill (tracking ball only) |
| YOLO notebook | first runs of the YOLO26 ball detector |
| YOLO-ball pipeline | anchored YOLO fills + `D` boundaries snapped to physical events |
| base pipeline | + video touch evidence + referee whistle |
| re-timing, smoothed-ball, nearest-player, stacking | four experiments on top of the base pipeline, all rejected |
| final pipeline | base pipeline + Laws-of-the-Game ball-out rule (the submission) |

Some names in this log are the Indonesian names used in the code (e.g. `celah ala BAR-ATH` = "BAR-ATH-like ball
gaps", `bola terlihat` = "ball visible", `sepak pojok` = corner kick); the glossary at the top of the final notebook
lists them.
